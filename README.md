# multi-xlsx_merge

一次彙整**多個相同版型**的 Excel 工作表（自動偵測資料範圍），產生加總總表，
可匯出 JSON / CSV / HTML / XLSX。所有運算都在瀏覽器本機完成，檔案不會上傳。

上線位置：<https://cormort.github.io/multi-xlsx_merge/>

## 使用流程

1. **上傳檔案**：拖曳或點選多個 `.xlsx` / `.xls`（可分批拖入，會累積；同名同大小視為重複）
2. **選擇版型**：內建四種基金報表版型（收支餘絀表、現金流量表、餘絀撥補表），
   或按「自動偵測範圍」用多數決決定範圍與標頭列數
   - 版型設定可匯出／匯入 JSON（含排序清單與基金名稱對照）
3. **確認欄位**：勾選要加總的數值欄位；第一欄預設為分析欄位（項目／科目）。
   純文字欄（例如「說明」）預設自動設為「忽略」。支援「欄列轉置」。
4. **查看報告**：加總總表（含合計列）、檔案查詢、項目查詢，並可匯出四種格式。

## 檔案結構

| 檔案 | 說明 |
| :--- | :--- |
| `index.html` | 畫面（含 SheetJS CDN 載入與 SRI 驗證） |
| `scripts.js` | 主程式：DOM、檔案讀取、彙總流程 |
| `lib.js` | **純函式層**（不碰 DOM，可在 Node 直接測）：數字解析、範圍偵測、CSV／HTML 字串處理、基金名稱比對 |
| `test-lib.mjs` | 純函式回歸測試（免安裝、秒級）：`node test-lib.mjs` |
| `tools/make-fixtures.py` | 產生端對端測試用的 Excel（含括號負數、千分位、附註列、雜訊欄） |
| `fixtures/*.xlsx` | 上述產物 |

## 測試

```bash
node test-lib.mjs                 # 純函式測試（17 項，無需安裝任何套件）
python3 tools/make-fixtures.py    # 重新產生端對端測試檔案
```

`lib.js` 以 UMD 形式輸出，瀏覽器用 `window.XlsxMergeLib`、Node 用 `import './lib.js'`，
因此測試與正式程式共用同一份邏輯，不需要複製貼上或字串切檔。

## 已知的資料處理規則（重要）

Excel 報表的數字常以文字儲存，且有幾種「陷阱格式」，`lib.js#toNumber` 會這樣處理：

| 儲存格內容 | 解析結果 | 說明 |
| :--- | :--- | :--- |
| `1234` / `1,234` | 1234 | 數字與千分位 |
| `(1,234)`、`（1,234）` | **-1234** | 會計式負數（舊版會變成 0，把虧損算成零） |
| `－1,234`、`−1,234` | -1234 | 全形負號、數學減號 |
| `１２３４` | 1234 | 全形數字 |
| `1,234元` | 1234 | 單位後綴 |
| `55%`、`2024/01/01`、`小計` | （忽略） | 非數字不參與加總 |
